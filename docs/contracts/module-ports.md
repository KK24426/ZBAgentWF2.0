# Module Ports

## 当前状态

当前没有业务公开端口、DTO、事件、状态枚举或进程协议。四个 `package-info.java` 只声明包边界，不是公开契约。

## 记录规则

用户创建或批准第一个公共接口后，在这里记录：

- Java 完整限定名；
- 接口所有者模块；
- 调用方向；
- 输入、输出和错误语义；
- 是否涉及状态、事务或副作用；
- 兼容性承诺和验证入口。

字段级事实以用户编写的 Java 接口及其测试为准。AI 不得先在本文发明契约，再据此生成接口。
