# Open Issues

以下事项均为“待用户确认”，不是当前项目事实：

1. 第一条纵向业务链路及其验收标准；
2. 第一批领域对象、用例接口和出站端口；
3. 是否使用 Spring 或保持纯 Java 组合；
4. 数据库、迁移工具和各环境目标；
5. Agent provider 和执行权限边界；
6. runtime host 的协议和生命周期；
7. Windows 客户端是复用、重写还是延后；
8. 开源许可证。

任何一项开始实施前，应由用户给出选择或明确授权 AI 提供候选方案。
