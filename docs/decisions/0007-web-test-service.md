# ADR 0007：Web服务与远程专用测试环境

- 状态：accepted
- 日期：2026-09-23
- 决策人：zebiao
- 替代：0005的CLI入口；0006的CLI生命周期、禁止Web和仅本机数据库环境约束。

用户要求由命令操作改为网页，明确只保留Web、先做简单首页，并批准技术入口、配置、根规则同步及指定远程测试环境。
保留Java26、单Maven工程和user/agent/common；采用Spring Boot Web MVC和内嵌Tomcat，无前端构建工具、额外架构层或业务API。
无参数启动长驻服务，环境变量/JVM属性/外部文件配置，移除help/version及旧CLI代码。
首页为静态HTML/CSS/SVG；固定资源白名单及安全请求摘要日志，后续业务路由由用户决定。
正常停止有20秒优雅关闭窗口；部署容器停止窗口30秒。运行期日志故障拒绝后续请求并提示检查，不静默丢失日志。

用户指定的远程测试服务器使用独立Web容器和现有MySQL实例中的新zbagentwf_test库、受限账号。
不改动其它项目数据库、账号、服务、端口或防火墙。凭据只保存在仓库外的受限文件，不进入Git或日志。
Web只监听127.0.0.1，通过SSH隧道访问；mysql-it同样走回环隧道，仍限制专用库，随机测试表测试后清理。
部署Java26官方运行镜像固定digest，非root、资源限额、只读根文件系统、独立日志目录；不安装或替换系统JDK。

代价：需保持SSH隧道；当前无公网访问、登录和业务页面；日志需人工管理；服务器共享资源但不共享业务数据或账号。
用户业务所有权、双阶段独立评审和提交推送门禁不变。
