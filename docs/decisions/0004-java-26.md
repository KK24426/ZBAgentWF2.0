# ADR 0004：升级到 Java 26

- 状态：accepted
- 日期：2026-08-09
- 决策人：zebiao
- 替代：[ADR 0001：采用 Java 21 和 Maven](./0001-java-maven.md)

## 背景

用户当前开发环境使用 JDK 26，并明确要求新项目以该版本作为统一开发和编译基线。ADR 0001 的 Java 21 决策不再符合实际环境。

## 决策

- 使用 Java 26 作为语言、编译和本地验证基线；
- Maven Wrapper 继续固定 Apache Maven 3.9.16；
- Maven Enforcer 只接受 `[26,27)`，避免使用其它 JDK 时产生不可追溯差异；
- 当前仍不引入 Spring 或其它应用框架。

## 影响

- 本机开发、CI 和后续构建环境都必须提供 JDK 26；
- 编译产物不承诺在低于 Java 26 的运行时上工作；
- ADR 0001 的 Maven、Wrapper 和“不引入框架”部分继续有效，Java 版本部分由本决策替代。

## 备选方案

- 保持 Java 21：与用户当前环境和明确选择不一致，未采用。
- 使用宽松 JDK 范围：会降低构建可复现性，未采用。
