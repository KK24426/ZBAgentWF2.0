# ADR0011：页面与接口消息本地化

- 状态：accepted
- 日期：2026-09-27
- 依据：用户逐字批准《页面与接口提示本地化》计划并请求实施。

## 决定

项目自有网页和固定HTTP提示由独立UTF-8 msg properties提供中、英、日译文，支持外部同语言逐key覆盖，启动校验并在重启时加载。日志、内部异常、启动及容器原生诊断保留现状；用户输入和模型输出不做翻译。

根包负责显式读取及装配，common.msg保存不可变消息目录，agent.web负责请求语言和首页适配；用户已授权ChatController仅修改注入和文案查询。语言按手动Cookie、服务配置、浏览器请求头、中文兜底决定，不依赖JVM默认Locale。

首页保留已有路径，将模板移至非公开资源位置。消息经HTML转义，三语前端消息用JSON序列化后再做HTML文本转义，放入inert template；浏览器通过textContent处理。此方式无需新增翻译/设置HTTP API、模板依赖或放宽CSP。HTML与脚本共用msg数据，切换保留当前输入及结果。

## 影响

外部翻译修改需重启，未知键或参数不匹配在启动时失败。参数只做编号文本替换，不提供富文本及复杂语法。语言Cookie仅保存偏好，浏览器禁用Cookie时持久化不保证。模型调用、业务接口、DTO、HTTP状态及存储边界保持原契约。细节和验收入口见[消息契约](../contracts/msg.md)及[本地开发](../operations/local-dev.md)。
