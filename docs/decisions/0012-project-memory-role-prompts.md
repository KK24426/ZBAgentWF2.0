# ADR 0012：内存项目、角色选择与提示词隔离

日期：2026-09-27；状态：用户已批准。

用户要求多种对象临时保存在应用内存，并补齐自己定义的ProjectDomain、共享Bean及ProjectController；确认角色与模型独立，显式选择优先于角色默认值，任意已接入可用模型可承担任何角色。

采用common中的单例MemoryStore，以分类和ID保存对象引用，无自动过期、持久化或重启恢复。项目在创建及首次规划成功后登记，通过ID返回原对象；HTTP以ID定位服务端对象并返回不可变视图，不暴露运行时引用或路径。

每个项目分别创建三角色Agent实体并初始化独立执行器。工厂按实体身份绑定，深拷贝模型元数据、角色Prompt和Skill；相同模型仍可复用既有执行资源额度和生命周期管理，但不会共享可变角色/项目状态。用户完整选择优先于启动时读取的三角色默认映射；配置缺失不自动选择模型。

通用、安全、角色规则由固定UTF-8文件显式加载，用户提供实际内容。构造器不调用抽象初始化方法；初始化完成后分段组合规则，项目规则追加影响后续调用。必要规则缺失在进程启动前拒绝；Skill暂时仅保存名称。提示词不替代原sandbox或其它执行权限约束。

本决定替代ADR0010中同模型共享执行器、删除newProject(content)、无角色默认值的部分；原注册、共享额度、诊断、关闭、只读规划及模型验收边界保持。HTTP五个入口及配置细节集中记录于[项目与执行契约](../contracts/project-agent.md)，无数据库、项目网页、自动审核流程或部署扩展。
