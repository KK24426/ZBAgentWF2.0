# ADR 0009：项目数据归属、执行声明与必填根目录

- 状态：accepted
- 日期：2026-09-25
- 决策人：zebiao

用户批准 Project 包含多条 Requirement、每条 Requirement 包含多个 RequirementTask，采用独立 Java Bean 与 List 表达，不增加持久化 schema 或反向关联。Task 保存五种已批准状态及单次执行结果，状态流转和调度尚未实现。

用户选择本机 CLI 方向、单次异步提交与最终回调、需要确认时结束本次执行并重新提交。ProjectUserif 的项目级执行仍等待底层结束后返回需求列表。当前只定义接口和类型，真实工具协议、线程与任务调度、目录创建、需求规划和列表增删留待后续实现。

用户要求新增项目类集中保存标识、目录与需求；所有项目操作显式传递 Project。AgentChatImpl 不应继承提供工具发现方法的 AgentBase，本次去除继承，保持既有聊天503行为。

用户选择应用初始化时读取全局项目根目录，并明确要求必须配置、不提供默认值。通过现有 Spring 机制读取外部 config/project.properties 中的 zb.project.root，支持环境变量与 JVM 属性覆盖。初始化规范化相对路径、拒绝缺失及非法配置，允许目录尚不存在，但不创建目录。

该选择使未配置项目根目录的旧启动方式失败；IDE、JAR 及后续部署说明必须同步，回归测试显式提供独立临时配置。没有新增配置框架或业务 Web API，也不改变现有包职责及数据库边界。
