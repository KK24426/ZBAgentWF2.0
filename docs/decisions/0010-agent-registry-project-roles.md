# ADR 0010：配置注册、工厂与项目 Agent 角色

日期：2026-09-26；状态：用户已批准。

模型身份使用 AgentBean 的 brand/name/ver，配置文件提供该身份到实现类型、原生CLI路径、模型参数、启用状态和单次超时的映射。AgentBean本身仍是原样存取的普通Bean。初始化不调用真实模型；文件可执行性与账号可用性分别验收。

根配置类由Spring装配AgentBase、AgentExecFactory与ProjectUserif。工厂按不可变三元组复用实例，负责资源关闭；Project保存规划、开发、审核三个AgentExecutor引用。用户明确批准此处common实体引用user抽象；不将该许可推广到其它包职责。创建项目时调用方显式选择三个模型，旧无模型入口删除，不保留只抛未支持的兼容壳。审核角色仅绑定，业务流程另行定义。

规划适配在agent实现内部与绑定的执行器关联，保留read-only及独立输出schema；不借执行摘要转换规划协议。首轮只支持Codex，不引入数据库模型注册、默认模型或配置热替换。

共享工厂的规划/执行合计最多4个受理名额，无等待队列。已完成stderr最多256条、保留30分钟，运行中不淘汰，Task结果独立保留。关闭事件停止受理并中断工作，从此时起Agent资源最多等待20秒；销毁使用相同截止时间，等待票据而非同步调用线程终止。单任务超时由模型配置独立控制，Spring其它关闭阶段不包含在该预算承诺中。

配置条目按键合并字段，支持高优先级单字段覆盖；重复模型身份和非法值失败。空注册表保留原Web启动行为，获取Agent时明确不可用。配置示例入仓，实际文件忽略。真实模型验收按用户决定在初期功能完成后开展。

详细行为、迁移及边界见[项目与执行契约](../contracts/project-agent.md)和[本地启动](../operations/local-dev.md)。
