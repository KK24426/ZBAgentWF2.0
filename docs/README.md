# 文档中心

新任务先读根 [AGENTS.md](../AGENTS.md)、目标目录就近规则和[需求台账](../REQUIREMENTS.md)。按任务使用[开发技能](../.agents/skills/zb-development/SKILL.md)或[审核技能](../.agents/skills/zb-review/SKILL.md)，具体资料按需读取。

- [architecture/overview.md](architecture/overview.md)、[module-boundaries.md](architecture/module-boundaries.md)：架构事实与依赖边界。
- [contracts/module-ports.md](contracts/module-ports.md)、[open-issues.md](contracts/open-issues.md)：批准的公开契约与待确认事项。
- [code-map/modules.md](code-map/modules.md)、[files.md](code-map/files.md)：职责、验证入口和源码定位。
- [decisions/](decisions/)：长期技术决定及取舍。
- [operations/local-dev.md](operations/local-dev.md)、[remote-test.md](operations/remote-test.md)、[asset-policy.md](operations/asset-policy.md)：构建、运行环境与资产规则。
- 审核空白模板随审核技能维护；具体任务记录位置和使用规则见该技能。

真实代码和 Maven 配置是最终依据；不一致须报告并修正，待确认事项不能写成事实。
