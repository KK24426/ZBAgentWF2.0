# Quality Gates

## 所有修改

- 说明用户需求、修改范围和不涉及范围；
- 遵守就近 `AGENTS.md`；
- 不擅自修改用户拥有的公共边界；
- 运行目标模块测试和 `mvnw.cmd verify`；
- 检查文档与代码事实一致；
- 报告未验证项和剩余风险。

## 功能实现

- 接口和验收条件已经由用户定义或批准；
- 覆盖主路径、失败路径和至少一个回归路径；
- adapter 不复制领域规则；
- 外部异常保留来源和可脱敏诊断；
- 资源释放、超时和取消行为可见。

## 公共边界变更

- 有用户明确指令；
- 说明调用方、兼容性和迁移影响；
- 更新契约索引、架构和 code map；
- 执行 Plan Review 和 Result Review。

## 数据和外部副作用

- 环境、数据库和目标配置已经明确；
- 写入、事务、重试、取消和失败状态显式；
- 不在构造函数、getter 或静态初始化中隐藏关键副作用；
- 日志、错误和测试证据不包含敏感信息。

## 发布

- 工作区范围清楚；
- 构建和测试通过；
- `git diff --check` 通过；
- 敏感信息扫描通过；
- remote、branch、upstream 和是否需要 force 均已确认；
- 推送后核对远端 commit。
