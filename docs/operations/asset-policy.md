# Asset Policy

## 禁止入仓

- token、API key、password、账号和登录材料；
- SSH/PGP 私钥、证书私钥、`.pfx`、`.p12`、`.key`、`.pem`；
- 生产配置、真实数据库、用户隐私和未脱敏日志；
- 本地 IDE、Agent 会话、缓存和临时下载；
- 未经确认有再分发权的第三方二进制。

只提交脱敏示例和 `.env.example`。配置示例必须使用明显占位符，不能使用看似真实的值。

## 公开仓库

推送前扫描常见 token 前缀、私钥块和敏感赋值形态。发现疑似敏感信息时停止；不要仅删除当前文件后继续，因为它可能已经进入 Git 历史。

当前仓库自有代码未选择开源许可证，AI 不得擅自添加项目级许可证或声明第三方可以自由使用。已纳入仓库的第三方组件必须保留其适用的许可证与通知，且明确许可范围。
