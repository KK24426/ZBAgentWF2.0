# Agent Workflow

本文件只解释协作流程。用户所有权、AI 修改权限、停止条件和规则优先级以根目录及目标模块的 `AGENTS.md` 为唯一规范权威。

## 标准流程

```text
用户定义目标、框架和接口
  -> AI 复述边界与验收条件
  -> AI 实现具体功能和测试
  -> AI 运行验证并说明结果
  -> 用户继续调整设计或进入下一条纵向链路
```

## Review 分级

Review 触发范围以根 `AGENTS.md` 为准。需要双阶段评审时使用 `docs/templates/review/`；Reviewer 不可用时保留 review packet 并交给其它独立 Agent 或用户，不得把未审核写成已通过。

## 提交与推送

默认不自动 commit 或 push。用户明确要求发布时，先完成测试、diff、敏感信息和目标远程检查，再提交和推送；不得 force push 或改写历史。
